## 一、Helix 工程哲学（八条，最高位阶）

1. **极致解耦**——模块间只经 schema/契约通信，无隐式耦合；
2. **按需加载**——请求只带本轮所需；模块惰性求值，无请求零活动；
3. **按需驱动**——一切能力显式声明、按需启用，无默认开启的隐性行为；
4. **极致复用**——同一资产（schema/判据/时钟/回退链）只存在一份；
5. **物理事实优先**——用真实代码/真实流量验证假设，不按文档照搬；
6. **确定性优先**——同输入 → 位级相同输出（熵增路由以 instance-id 去相关，
   同 instance 恒同输出）；
7. **0 硬编码**——每个字面量（阈值/模型名/时间窗/循环上限）必须有来源
   （config/契约/派生/协议默认）；
8. **极致节能**——0 tokens 优先 > 少 tokens/小 LLM > 多 tokens/大 LLM（默认通道
   不是教条，判断点按 ROI 显式选后端）。

## 二、FlowModus 铁律（继承 manual v1.1.3 + whitepaper v1.7，重构不变量）

0. **最小作用量**——废除一切定时轮询与主动探测；遥测 100% 寄生于真实业务数据流；
   **唯一例外：用户显式触发的按需探测**（成本须在 UI 提前告知）。
   ※ 注：whitepaper v1.7 §5.5 的"每小时 Canary Probe"为**文档滞后**——manual
   v1.1.3（更晚）铁律 0 已收紧；rs 重构以铁律 0 为准（ADR-0100 记录）。
1. **确定性优先**——静态规则确定性（声明数据，绝对可复现）与动态状态自适应
   （延迟/可用性，有明确熔断阈值）严格隔离；熵增路由 = instance-id 去相关，
   非概率黑盒；
2. **纯函数**——路由逻辑无副作用（side-effect-free）；
3. **无锁**——消息传递优于共享内存，无死锁；
4. **无阻塞**——异步 I/O 唯一；控制面与数据面分离；
5. **Schema 强制**——模块间 protobuf 契约，禁止裸 dict/JSON；
6. **极简依赖**——无 web 框架、无 ORM、无 daemon、无 UI；
7. **命名即文档**——Google 风格，自解释命名（Helix：零行业词汇）。

## 三、度量衡三件套（第一范式，不可变资产）

| 件 | 资产 | 不可变约束 |
|---|---|---|
| 度 | STE 标准 Token 当量 | 统一标尺定义不可变；只作比较辅助，不进审计逻辑 |
| 校准 | 声明偏移量（纯数学偏差） | 自动计算、自动公开、**不做任何评级**；实测永不覆盖静态声明 |
| 检定 | 一致性测试（计费精度/TTL 漂移/响应时间/语义标签） | 只呈现数据、不设通过标准、不人工审核 |

**铁律**：**FlowModus 不判断。FlowModus 只呈现。判断权永远属于用户。**

## 四、五层确定性路由管线（不可变资产，whitepaper 定义）

```
L1 协议与度量规范层（STE / Unicode NFC / 协议契约）
L2 供应商原始模型层（Ed25519 签名注册表，忠实原文，无主观评价）
L2.5 确定性基准测试层（声明偏移量 = 寄生遥测 + 按需探测，无定时心跳）
L3 标准化计价与评估层（Estimated_Cost_USD）
L4 用户偏好与硬边界（Hard Filter）
L5 Agent 意图与动态偏好（Soft Weighting + 熵增路由）
```

- 层顺序不可变、不可跳过；层间 protobuf 契约；
- **新增语义（吸收成熟实践，不造轮子）**：失败冷却 + 恢复（one-api 运维语义，
  确定性来源真实流量遥测——非探测）；模型别名/重定向（注册表层可验证映射）。

## 五、独立中立（重构不变量）

- 核心 crate **零 Helix 依赖**——FlowModus 是可被任何 Agent 框架单独使用的独立协议；
- 编排优先，拒造实体：只提供数据标准（KV Cache 声明/STE/偏移量），不干预消费者
  决策逻辑；
- 凭证零接触：密钥永存本地、绝不传输；调度决策全部本地完成。

## 六、显式边界（不是 FlowModus 的事）

- 不持有凭证（Tuck/用户本地）；不做权限分组（CAPABILITY-13）；不做 UI/展示
  （消费者驾驶舱）；不做网关/管理台（不重复造第三方管理台的轮子）；不做在线
  学习路由（M3 边界，未来开放项）；不做守护进程。
